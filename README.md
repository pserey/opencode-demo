# OpenCode demo

Este repositório nasceu de uma demonstração do workflow que uso atualmente para desenvolvimento assistido por agentes.

Ele contém um workspace com instruções persistentes, uma área local para artefatos de planejamento e as skills usadas para especificar e implementar mudanças.

## Estrutura

- `workspace/`: ponto de partida da demonstração, com o `AGENTS.md` e `artifacts/` inicialmente vazio.
- `skills/`: versões portáveis de `demo-specify-plan` e `demo-implement-plan`.

Os artefatos são locais por padrão e não devem ser versionados nos repositórios de código em que o trabalho é realizado.
